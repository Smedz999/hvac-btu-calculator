How it works

  • Base load is calculated from floor area using industry-standard BTU per square metre/foot values.
  • Ceiling height adjusts for air volume — higher ceilings need more cooling power.
  • Insulation, sun exposure, and room type apply percentage modifiers based on typical heat gain.
  • Occupants add ~600 BTU per person beyond the first two.
  • The final result is rounded up to the nearest standard residential AC unit size.
